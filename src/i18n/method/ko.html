방법론 및 데이터 출처

경계선이 어떻게 계산되고 모든 숫자가 어디서 오는지, 그리고 이 도구가 의도적으로 주장하지 않는 것.

답하는 질문

비교 사이트는 가격을, 리더보드는 점수를 보여줍니다. 이 도구는 양쪽을 결합해 의사결정 등급의 질문에 답합니다: 수용 가능한 최소 Arena 점수(임계값 T)가 주어졌을 때, 실측 태스크당 비용이 가장 낮은 모델은? 형식화하면 C(T) = min{cost : score ≥ T}. T를 위에서 아래로 스윕하면 비용-품질 파레토 경계선 —— 각 평평한 구간이 한 모델이 지배하는 점수 범위인 계단 —— 이 얻어집니다. 표는 한 티어 위로 올라가는 한계 가격(Δcost/Δscore, $/pt)도 보고합니다. 구매 결정이 실제로 의존하는 바로 그 숫자입니다.

「최고 가성비」의 세 가지 정의

  • 임계값(Threshold)(기본값): 점수 ≥ T인 최저가 모델. 제약 최적화로서 올바른 유일한 정의.
  • 달러당 점수: Arena의 Bradley-Terry 점수가 ~1200 기준선 오프셋을 가져 저렴한 모델에 크게 편향.
  • 초과 점수/$: 먼저 1200 하한을 뺌; 한계 가치에 더 가깝지만 여전히 편향됨.

데이터 출처와 스냅샷 날짜

  • 점수와 Cost/Task: 공개 arena.ai WebDev 리더보드 및 하위 보드, 스냅샷 2026-11-21(2026-11-14 수집). 자동 갱신에는 공식 기계 가독 미러 권장: Hugging Face의 lmarena-ai/leaderboard-dataset.
  • 가격: 각 벤더 1차 API 정가(입력/출력 백만 토큰당), benchr.org/pricing(2026-09-11 스냅샷)와 항목별 대조로 검증. 오픈소스 모델은 벤더 호스팅 API 가격으로 게재되며 셀프호스팅 비용이 아닙니다.
  • Cost/Task (P50) = Arena 태스크의 실측 토큰 사용량 중앙값 × 정가 —— 캐시 미스 기준. P50은 꼬리를 숨기고(P95는 5–10배 가능) 토큰 비용만 커버합니다.

시간의 함수로서의 가격

정가는 시간대와 캘린더에 따라 바뀝니다. 기본 적용되는 검증된 규칙: DeepSeek 피크/비피크(피크 = 평일 01:00–04:00 및 06:00–10:00 UTC, 2×; 그 외 ½×) —— 보드 자체가 같은 계열의 피크 가격 행과 비피크 가격 행을 한 표에 섞어 놓음; Gemini 4 Carbon/Argon 2026-12-01 인상($2/$10 → $4/$20). 불확실한 규칙(DeepSeek V4-Flash 피크 분할; 두 모델이 제3자 인덱스와 2× 차이)은 수록했지만 기본 꺼짐.

캐시 모델

리더보드 비용은 0% 캐시 히트를 가정하여 agent 워크로드를 체계적으로 과대평가합니다. 실효 입력 가격 = (1−h)·pin·wm + h·pin·ratio; 출력은 절대 할인되지 않습니다. 캐시 읽기 가격은 정가 입력 가격에 대한 비율로 저장됩니다(DeepSeek 2–3.3%, MiMo 0.8–2%, Kimi 10–20%, GLM 18–20%, Hy3/Grok 25%, Anthropic 2.5–10%, OpenAI 5–10%, Gemini 5%, Mistral 10.3%; 미지 → 10% 추정, 라벨 표시). 쓰기 배율 wm: Anthropic/OpenAI(모델명이 Claude/GPT-로 시작)는 1.25×, 그 외 1.0×. h=95%에서 상위 모델 실효 비용은 59–79% 하락하고 경계선 자체가 재정렬됩니다.

엄격 CI 모드

95% CI가 겹치는 인접 티어는 병합됩니다(더 저렴한 모델 유지) —— 통계 노이즈에 돈을 쓰지 않기 위함입니다. 이는 보수적인 겹침 스크리닝이며 점수 차의 정식 검정이 아님에 유의하세요.

한계

  • 점수는 스냅샷; 보드 업데이트에 따라 능력도 표류합니다. 가격은 매주 표류합니다.
  • P50 태스크 비용은 워크로드 혼합입니다; 당신의 워크로드는 다릅니다. 자신의 청구서로 붙여넣기 확장 기능을 사용하세요.
  • 전체 라이선스 보드는 상위 41행만 커버; 오픈소스 보드는 완전합니다.
  • 신뢰도: 여기의 모든 숫자는 공개 페이지로 소급됩니다; 각 보정에는 도구 안에 출처가 붙어 있습니다.

Arena × 가격: 공식 가성비 목록은 없다 —— 누가 채우고 있나

2026-11-23 기준 시장 구도(arena.ai 어드바이저 세션에서 검증): OpenRouter는 공식적으로 「Arena 리더보드 × 가격」 가성비 목록을 공개하지 않았다 —— 점수 보드와 가격 체계는 별개 데이터이며 공식은 양자를 결합하지 않는다. 공식에서 가장 가까운 세 가지 입구:

  • Rankings 페이지의 Benchmarks 섹션: 가격 × 지능 지수 산점도(가중 평균 입력 가격 × Artificial Analysis Intelligence Index), 원클릭 파레토 전환 —— 공식 페이지에서 「가성비」에 가장 가까운 뷰지만, 품질 축은 Arena Elo가 아니라 제3자 지능 지수다.
  • 자체 벤치마크 라이브러리 openrouter.ai/benchmarks: 18개 벤치마크, 220만+ 태스크 평가, 각 점수에 비용·지연 데이터 포함, Benchmarks API 제공; Design Arena의 ELO 보드는 2026-03부터 여기에 삽입됨.
  • 가격 전량 공개: openrouter.ai/models과 /api/v1/models로 모델별 입력/출력/캐시 가격을 프로그램 방식으로 가져올 수 있음.

과금 기준(이 사이트가 1차 정가를 쓰는 이유): 집계 채널은 추론 자체에 마크업을 붙이지 않고 요금은 충전 단계에 있다(OpenRouter 약 5.5%, 2026-11 검증); 같은 모델도 provider별로 독립적으로 가격을 매기며 제3자 목록은 항상 최저가를 취한다. 이 사이트는 벤더 1차 API 정가를 사용; 집계 채널을 통해 구매하면 실지불 ≈ 채널 최저가 + 충전 수수료로, 이 사이트 숫자와 한 자릿수 %의 체계적 차이가 있다.

「Arena × 가격」을 결합 중인 제3자: Artificial Analysis(지능 지수 × 가격), arena.atease.dev(중국어, Arena 각 보드 × OpenRouter 최저가), pricepertoken.com / cloudprice.net(엔드포인트 가격 집계). Arena 점수를 태스크 수준 비용 파레토로 환산하는 것은 현재 제3자만 —— 이 사이트를 포함해서다.
