答える質問

比較サイトは価格を、リーダーボードはスコアを見せます。本ツールは両者を結合し、意思決定グレードの質問に答えます：許容できる最低 Arena スコア（しきい値 T）を与えたとき、実測コスト/タスクが最も低いモデルはどれか？形式化すると C(T) = min{cost : score ≥ T}。T を下方向へスイープすると、コスト-品質パレートフロンティア —— 1つのモデルが支配するスコア範囲が各平坦部になる階段 —— が得られます。テーブルは1つ上のTierへの限界価格（Δcost/Δscore、$/pt）も報告します。購買意思決定が実際に依存するのはこの数字です。

「最コスパ」の3つの定義

  • しきい値（Threshold）（デフォルト）：スコア ≥ T の最安モデル。制約付き最適化として正しい唯一の定義。
  • ドルあたりスコア：Arena の Bradley-Terry スコアが ~1200 のベースラインオフセットを持つため、安いモデルに強く偏ります。
  • 超過スコア/$：先に 1200 の床を引きます；限界価値に近いですが、まだ偏りがあります。

データソースとスナップショット日付

  • スコアと Cost/Task：公開の arena.ai WebDev リーダーボードとサブボード、スナップショット 2026-11-11（2026-11-14 に取得）。自動リフレッシュには公式の機械可読ミラーを推奨：Hugging Face の lmarena-ai/leaderboard-dataset。
  • 価格：各ベンダー一次の API 定価（入力/出力 100万トークンあたり）、benchr.org/pricing（2026-09-11 スナップショット）と1件ずつ照合して検証。オープンソースモデルはベンダーホストの API 価格で掲載されており、セルフホスティングコストではありません。
  • Cost/Task (P50) = Arena タスクの実測トークン使用量の中央値 × 定価 —— キャッシュミス基準。P50 は裾を隠し（P95 は 5–10× になり得る）、トークン費用のみをカバーします。

時間の関数としての価格

定価は時間帯とカレンダーで変わります。デフォルトで適用される検証済みルール：DeepSeek ピーク/オフピーク（ピーク = 平日 01:00–04:00 と 06:00–10:00 UTC、2×；それ以外 ½×）—— ボード自体が同一ファミリーのピーク価格行とオフピーク価格行を1つの表に混ぜています；GLM-5.3-Flash プロモ期限切れ（2026-09-09：$0.05/$0.18 → $0.15/$0.50）；Gemini 4 Carbon/Argon 2026-12-01 値上げ（$2/$10 → $4/$20）。不確実なルール（DeepSeek V4-Flash のピーク分割；2モデルが第三者インデックスと 2× 差）は収録していますがデフォルトオフです。

キャッシュモデル

リーダーボードのコストは 0% キャッシュヒットを仮定しており、agent ワークロードを体系的に過大評価します。実効入力価格 = (1−h)·pin·wm + h·pin·ratio；出力は決して割引されません。キャッシュ読取価格は定価入力価格に対する比率で保存されます（DeepSeek 2–3.3%、MiMo 0.8–2%、Kimi 10–20%、GLM 18–20%、Hy3/Grok 25%、Anthropic 2.5–10%、OpenAI 5–10%、Gemini 5%、Mistral 10.3%；未知 → 10% 推定、ラベル付き）。書き込み倍率 wm：Anthropic/OpenAI（モデル名が Claude/GPT- で始まる）は 1.25×、それ以外 1.0×。h=95% で上位モデルの実効コストは 59–79% 低下し、フロンティア自体が並べ替わります。

厳密 CI モード

95% CI が重なる隣接Tierは統合されます（安いモデルを保持）ので、統計ノイズにお金を払わずに済みます。これは保守的な重なりスクリーニングであり、スコア差の正式な検定ではないことに注意してください。

限界

  • スコアはスナップショット；ボードの更新とともに能力もドリフトします。価格は週ごとにドリフトします。
  • P50 タスクコストはワークロード混合です；あなたのワークロードは異なります。自分の請求で貼り付け拡張機能を使ってください。
  • 全ライセンスボードは上位 41 行のみカバー；オープンソースボードは完全です。
  • 信頼度：ここのすべての数字は公開ページに遡れます；各補正にはツール内で出典が付きます。
