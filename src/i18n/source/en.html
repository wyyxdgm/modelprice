Availability: pages are publicly readable and scrapeable; but arena.ai/api/* and api.arena.ai/* return 403 (Cloudflare + route allowlist) — no public JSON API. So this tool uses an "embedded snapshot + paste-to-extend" design instead of live requests.

Field semantics:

  • Score: Arena's Bradley-Terry-style rating; +u/−d is the bootstrap 95% confidence interval.
  • Cost/Task (P50): the median dollar cost of completing one Arena task = measured token usage × the API prices below. N/A = not published — such models are excluded by default (toggleable).
  • Price $/M: the vendor's first-party API list price (input / output per million tokens) — not a unified Arena-set price, and not the amortized cost of self-hosting. Note: a low Cost/Task doesn't mean a low unit price (it also depends on how many tokens the model emitted).

Whose prices are these, exactly? (checked item by item)

Compared one-by-one against the independent pricing index benchr.org/pricing (2026-09-11 snapshot), Arena's Price $/M equals each vendor's official API list price: Kimi K3.1 Pro $2/$10, Kimi K3 $3/$15 (Moonshot); GLM-5.2 / 5.3 $1.40/$4.40 (Z.ai); Claude Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50 (Anthropic); GPT-6.1 Sol $2/$10, Terra $1/$5, GPT-6 Astra $10/$50 (OpenAI); Grok 4.7 $2/$6, Gemini 4 Argon $2/$10; Mistral Large 4 $0.70/$2.10; MiniMax M3 $0.30/$1.20; DeepSeek V4-Pro $1.32/$3.96.

Open-source models are also listed at API prices — not what you'd pay self-hosting. Gemma 4 31B $0.16/$0.47, Granite 4.1 8B $0.05/$0.10, Hy3 $0.13/$0.53, Qwen3.8-27B $0.40/$3, MiMo-V2.6-Flash $0.14/$0.28 — these are the quotes of Google / IBM / Tencent / Alibaba / Xiaomi's own hosted endpoints (each model's link on the board points to those API docs). Open weights ≠ free inference: self-hosting costs are GPU amortization + power + ops, with no mapping to per-token list prices.

Cost/Task is computed from measured usage — three internal proofs:

  • A model's Price $/M is identical across all 7 boards in this tool → unit price is a model-level constant;
  • A model's Cost/Task is identical across the five WebDev sub-boards (Overall / Frontend / React / Reference-based / Fullstack) but differs on Image-to-WebDev (e.g. DeepSeek-V4.1-Flash-20261017: $0.12 vs $0.10) → usage is aggregated per task category, not per sub-board;
  • The Agent board also publishes Output Tokens/Task, from which input volume can be inferred: 14 models infer to 125K–1.27M input tokens, input/output ratios 3.8–17.9× — exactly a multi-turn tool-calling load signature. And (Max)/(High)/(xHigh) tiers share the same unit price while Cost differs 2–4× (Claude Opus 5.5: $5.66 vs $2.13) — entirely a token-usage difference.

Three price traps that make conclusions optimistic:

  • DeepSeek peak/off-peak. The board lists the 20261017 version at off-peak $0.15/$0.60 and the 20260910 version at peak $0.30/$1.20. Peak = weekdays 01:00–04:00 and 06:00–10:00 UTC; other hours are half price. If your workload can't be scheduled into off-peak, 20261017's $0.12/task doubles to ~$0.24: it still holds the 1664 tier (structure unchanged), but the "1638→1664" marginal price rises from $0.0027/pt to $0.0073/pt while "1664→1687" falls from $0.0343 to $0.0291 — the knee jump shrinks from 12.8× to 4.0×, weakening the urgency to stop there.
  • Board prices from promo-heavy labs can be stale in either direction. GLM-5.3-Flash: the 11-11 snapshot listed an expired launch promo ($0.05/$0.18, ended 2026-09-09; real price $0.15/$0.50) — the tool corrected it; the 11-20 snapshot lists $0.02/$0.07, below the post-promo price (likely a new promo), so the rule was retired 2026-11-22. Verify against the vendor pricing page before trusting Cost/Task.
  • No cache discount. DeepSeek cache-hit input $0.006 (peak) / $0.003 (off-peak); Anthropic cache input $0.10–$1.00. Multi-turn agent workloads hit cache often; real bills can be well below "list × tokens".
