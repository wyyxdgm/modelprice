フィールドの意味：

  • Score（スコア）：Arena の Bradley-Terry 型レーティング；+u/−d はブートストラップ 95% 信頼区間。
  • Cost/Task (P50)：Arena の1タスク完了にかかる中央ドルコスト = 実測トークン使用量 × 下記の API 価格。N/A = 未公表 —— 該当モデルはデフォルトで除外（切替可）。
  • Price $/M：ベンダー一次の API 定価（入力 / 出力 100万トークンあたり）—— Arena が統一設定した価格ではなく、セルフホスティングの償却コストでもありません。注意：Cost/Task が低くても単価が低いとは限りません（モデルが出力したトークン量にも依存します）。

この価格はいったい誰の価格？（1件ずつ確認済み）

独立価格インデックス benchr.org/pricing（2026-09-11 スナップショット）と1件ずつ照合した結果、Arena の Price $/M は各ベンダーの公式 API 定価と一致します： Kimi K3.1 Pro $2/$10、Kimi K3 $3/$15（Moonshot）；GLM-5.2 / 5.3 $1.40/$4.40（Z.ai）；Claude Opus 5.5 $4/$20、Sonnet 5.5 $2/$10、Haiku 5.5 $0.10/$0.50（Anthropic）；GPT-6.1 Sol $2/$10、Terra $1/$5、GPT-6 Astra $10/$50（OpenAI）；Grok 4.7 $2/$6、Gemini 4 Argon $2/$10；Mistral Large 4 $0.70/$2.10；MiniMax M3 $0.30/$1.20；DeepSeek V4-Pro $1.32/$3.96。

オープンソースモデルも API 価格で掲載されています —— セルフホスティングで払う金額ではありません。Gemma 4 31B $0.16/$0.47、Granite 4.1 8B $0.05/$0.10、Hy3 $0.13/$0.53、Qwen3.8-27B $0.40/$3、MiMo-V2.6-Flash $0.14/$0.28 —— これらは Google / IBM / Tencent / Alibaba / Xiaomi の自社ホスティングエンドポイントの見積もりです（ボード上の各モデルのリンクはそれらの API ドキュメントを指します）。オープンウェイト ≠ 無料推論：セルフホスティングコストは GPU 償却 + 電力 + 運用であり、トークンあたり定価への対応関係はありません。

Cost/Task は実測使用量から計算されている —— 3つの内部証拠：

  • 同一モデルの Price $/M は本ツールの全 7 ボードで完全に同一 → 単価はモデルレベルの定数；
  • 同一モデルの Cost/Task は 5 つの WebDev サブボード（Overall / Frontend / React / Reference-based / Fullstack）で完全に同一ですが、Image-to-WebDev では異なります（例：DeepSeek-V4.1-Flash-20261017：$0.12 vs $0.10）→ 使用量はタスクカテゴリごとに集計され、サブボードごとではありません；
  • Agent ボードは Output Tokens/Task も公表しており、そこから入力量を推定できます：14 モデルは 125K–1.27M 入力トークン、入力/出力比 3.8–17.9× に推定 —— まさにマルチターンツール呼び出し負荷の特徴。さらに (Max)/(High)/(xHigh) ティアは同一単価を共有しながら Cost は 2–4× 異なります（Claude Opus 5.5：$5.66 vs $2.13）—— 完全にトークン使用量の差です。

結論を楽観側に倒す3つの価格罠：

  • DeepSeek ピーク/オフピーク。ボードは 20261017 版をオフピーク $0.15/$0.60 で、20260910 版をピーク $0.30/$1.20 で掲載。ピーク = 平日 01:00–04:00 と 06:00–10:00 UTC；その他は半額。ワークロードをオフピークに配せない場合、20261017 の $0.12/タスクは ~$0.24 に倍増：それでも 1664 Tier は維持（構造不変）ですが、「1638→1664」の限界価格は $0.0027/pt から $0.0073/pt に上昇、「1664→1687」は $0.0343 から $0.0291 に低下 —— 膝点ジャンプは 12.8× から 4.0× に縮小し、そこで止まる緊急性が弱まります。
  • GLM-5.3-Flash は期限切れのローンチプロモ価格を使用 $0.05/$0.18；プロモは 2026-09-09 に終了、現価格 $0.15/$0.50（3×）なので、その $0.15/タスクは実際には約 $0.45。もともとフロンティアにはいませんでしたが、同様の古いプロモ価格が他のモデルを水増ししている可能性があります。
  • キャッシュ割引なし。DeepSeek キャッシュヒット入力 $0.006（ピーク）/ $0.003（オフピーク）；Anthropic キャッシュ入力 $0.10–$1.00。マルチターン agent ワークロードはキャッシュに頻繁にヒットします；実際の請求は「定価 × トークン」を大きく下回り得ます。
