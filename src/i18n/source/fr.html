Source : arena.ai/leaderboard/code/webdev et ses sous-classements (frontend / fullstack), extraits le %SCRAPED% ; données du classement datées du %CAPTURED%.

Disponibilité : les pages sont publiquement lisibles et scrapables ; mais arena.ai/api/* et api.arena.ai/* renvoient 403 (Cloudflare + liste blanche de routes) — pas d'API JSON publique. Cet outil adopte donc une conception « instantané intégré + collage pour étendre » au lieu de requêtes en direct.

Sémantique des champs :

  • Score : la note de type Bradley-Terry d'Arena ; +u/−d est l'intervalle de confiance bootstrap à 95 %.
  • Cost/Task (P50) : le coût dollar médian pour accomplir une tâche Arena = utilisation de tokens mesurée × les prix API ci-dessous. N/D = non publié — ces modèles sont exclus par défaut (bascule possible).
  • Price $/M : le prix catalogue API du fournisseur lui-même (entrée / sortie par million de tokens) — ni un prix fixé par Arena, ni le coût amorti de l'auto-hébergement. Remarque : un Cost/Task bas ne signifie pas un prix unitaire bas (cela dépend aussi du nombre de tokens que le modèle a émis).

Ces prix sont ceux de qui, exactement ? (vérifié point par point)

Comparés un par un à l'index de tarification indépendant benchr.org/pricing (instantané du 2026-09-11), les Price $/M d'Arena égalent le prix catalogue API officiel de chaque fournisseur : Kimi K3.1 Pro 2/10 $, Kimi K3 3/15 $ (Moonshot) ; GLM-5.2 / 5.3 1,40/4,40 $ (Z.ai) ; Claude Opus 5.5 4/20 $, Sonnet 5.5 2/10 $, Haiku 5.5 0,10/0,50 $ (Anthropic) ; GPT-6.1 Sol 2/10 $, Terra 1/5 $, GPT-6 Astra 10/50 $ (OpenAI) ; Grok 4.7 2/6 $, Gemini 4 Argon 2/10 $ ; Mistral Large 4 0,70/2,10 $ ; MiniMax M3 0,30/1,20 $ ; DeepSeek V4-Pro 1,32/3,96 $.

Les modèles open-source sont aussi listés aux prix API — pas ce que vous paieriez en auto-hébergement. Gemma 4 31B 0,16/0,47 $, Granite 4.1 8B 0,05/0,10 $, Hy3 0,13/0,53 $, Qwen3.8-27B 0,40/3 $, MiMo-V2.6-Flash 0,14/0,28 $ — ce sont les devis des points de terminaison hébergés par eux-mêmes de Google / IBM / Tencent / Alibaba / Xiaomi (le lien de chaque modèle sur le classement pointe vers ces docs API). Poids ouverts ≠ inférence gratuite : les coûts d'auto-hébergement sont l'amortissement GPU + l'électricité + l'exploitation, sans correspondance avec les prix catalogues par token.

Le Cost/Task est calculé à partir de l'utilisation mesurée — trois preuves internes :

  • Le Price $/M d'un modèle est identique sur les 7 classements de cet outil → le prix unitaire est une constante au niveau du modèle ;
  • Le Cost/Task d'un modèle est identique sur les cinq sous-classements WebDev (Overall / Frontend / React / Reference-based / Fullstack) mais diffère sur Image-to-WebDev (ex. DeepSeek-V4.1-Flash-20261017 : 0,12 $ vs 0,10 $) → l'utilisation est agrégée par catégorie de tâche, pas par sous-classement ;
  • Le classement Agent publie aussi Output Tokens/Task, d'où le volume d'entrée peut être inféré : 14 modèles s'infèrent à 125K–1,27M tokens d'entrée, ratios entrée/sortie 3,8–17,9× — exactement la signature d'une charge d'appels d'outils multi-tours. Et les paliers (Max)/(High)/(xHigh) partagent le même prix unitaire tandis que le Cost diffère de 2–4× (Claude Opus 5.5 : 5,66 $ vs 2,13 $) — entièrement une différence d'utilisation de tokens.

Trois pièges de prix qui rendent les conclusions optimistes :

  • Heures pleines/creuses DeepSeek. Le classement liste la version 20261017 en heures creuses 0,15/0,60 $ et la version 20260910 en heures pleines 0,30/1,20 $. Pointe = jours ouvrés 01:00–04:00 et 06:00–10:00 UTC ; les autres heures sont à demi-prix. Si votre charge ne peut pas être programmée en heures creuses, le 0,12 $/tâche de 20261017 double à ~0,24 $ : il garde le palier 1664 (structure inchangée), mais le prix marginal « 1638→1664 » monte de 0,0027 $/pt à 0,0073 $/pt tandis que « 1664→1687 » chute de 0,0343 à 0,0291 $ — le saut du coude se rétrécit de 12,8× à 4,0×, affaiblissant l'urgence de s'arrêter là.
  • GLM-5.3-Flash utilise un prix promo de lancement expiré 0,05/0,18 $ ; la promo s'est terminée le 2026-09-09, prix actuel 0,15/0,50 $ (3×), donc son 0,15 $/tâche est en réalité ~0,45 $. Il n'était de toute façon pas sur la frontière, mais des prix promos périmés similaires peuvent gonfler d'autres modèles.
  • Pas de remise de cache. Entrée cache-hit DeepSeek 0,006 $ (pointe) / 0,003 $ (creuse) ; entrée cache Anthropic 0,10–1,00 $. Les charges agent multi-tours touchent souvent le cache ; les vraies factures peuvent être bien en dessous de « catalogue × tokens ».

Vous voulez votre propre base de coûts ? Utilisez la boîte de collage ci-dessous et remplacez la colonne Cost/Task par vos factures mesurées ou vos coûts amortis d'auto-hébergement — le parseur lit les noms de colonnes et se moque de la provenance des chiffres. La frontière que vous obtenez est la vôtre.

  • Rank vs Overall Rank : le premier est le rang dans ce sous-classement/filtre de licence ; le second est le rang global tous modèles.
  • Preliminary (provisoire) : les votes n'ont pas atteint le seuil de stabilité ; les IC sont généralement larges.
  • AutoEval (auto-évalué) : score issu d'une évaluation automatisée plutôt que de batailles humaines — non directement comparable avec les scores de votes humains → exclu par défaut.

Limites de cet outil : les données sont un instantané, pas du direct ; le coût ne couvre que les dépenses de tokens ; la définition de la « valeur » est la vôtre et différentes définitions couronnent différents champions ; la signification statistique n'est imposée qu'en mode strict.

Conformité : les données proviennent de pages publiques et servent à une analyse personnelle. Ne scrapez pas arena.ai à haute fréquence. Si vous publiez des conclusions dérivées, attribuez la source de données et la date d'extraction.
