필드 의미:

  • Cost/Task (P50): Arena 태스크 하나를 완료하는 중위 달러 비용 = 실측 토큰 사용량 × 아래 API 가격. N/A = 미공표 —— 해당 모델은 기본 제외(전환 가능).

이 가격은 대체 누구의 가격인가?(항목별 확인 완료)

독립 가격 인덱스 benchr.org/pricing(2026-09-11 스냅샷)와 항목별로 대조한 결과, Arena의 Price $/M은 각 벤더의 공식 API 정가와 일치합니다: Kimi K3.1 Pro $2/$10, Kimi K3 $3/$15(Moonshot); GLM-5.2 / 5.3 $1.40/$4.40(Z.ai); Claude Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50(Anthropic); GPT-6.1 Sol $2/$10, Terra $1/$5, GPT-6 Astra $10/$50(OpenAI); Grok 4.7 $2/$6, Gemini 4 Argon $2/$10; Mistral Large 4 $0.70/$2.10; MiniMax M3 $0.30/$1.20; DeepSeek V4-Pro $1.32/$3.96.

오픈소스 모델도 API 가격으로 게재 —— 셀프호스팅에 지불할 금액이 아닙니다. Gemma 4 31B $0.16/$0.47, Granite 4.1 8B $0.05/$0.10, Hy3 $0.13/$0.53, Qwen3.8-27B $0.40/$3, MiMo-V2.6-Flash $0.14/$0.28 —— 이들은 Google / IBM / Tencent / Alibaba / Xiaomi의 자사 호스팅 엔드포인트 견적입니다(보드의 각 모델 링크는 해당 API 문서를 가리킴). 오픈 웨이트 ≠ 무료 추론: 셀프호스팅 비용은 GPU 상각 + 전력 + 운영이며, 토큰당 정가와의 환산 관계가 없습니다.

Cost/Task는 실측 사용량에서 계산됩니다 —— 세 가지 내부 증거:

  • 같은 모델의 Price $/M은 이 도구의 전체 7개 보드에서 완전히 동일 → 단가는 모델 수준 상수;
  • 같은 모델의 Cost/Task는 다섯 WebDev 하위 보드(Overall / Frontend / React / Reference-based / Fullstack)에서 완전히 동일하지만 Image-to-WebDev에서는 다릅니다(예: DeepSeek-V4.1-Flash-20261017: $0.12 vs $0.10) → 사용량은 태스크 카테고리별로 집계되지 하위 보드별이 아님;
  • Agent 보드는 Output Tokens/Task도 공표하여 입력량을 역산할 수 있음: 14개 모델은 125K–1.27M 입력 토큰, 입력/출력 비 3.8–17.9×로 역산 —— 정확히 멀티턴 도구 호출 부하의 특징. 그리고 (Max)/(High)/(xHigh) 티어는 같은 단가를 공유하면서 Cost는 2–4× 차이(Claude Opus 5.5: $5.66 vs $2.13) —— 전적으로 토큰 사용량 차이입니다.

결론을 낙관 쪽으로 기울게 하는 세 가지 가격 함정:

  • DeepSeek 피크/비피크. 보드는 20261017 버전을 비피크 $0.15/$0.60로, 20260910 버전을 피크 $0.30/$1.20로 게재. 피크 = 평일 01:00–04:00 및 06:00–10:00 UTC; 나머지 시간대는 반값. 워크로드를 비피크에 배치할 수 없다면 20261017의 $0.12/태스크는 ~$0.24로 두 배: 여전히 1664 티어를 지키지만(구조 불변), 「1638→1664」 한계 가격은 $0.0027/pt에서 $0.0073/pt로 상승하고 「1664→1687」은 $0.0343에서 $0.0291로 하락 —— 무릎점 점프가 12.8×에서 4.0×로 축소되어 거기서 멈춰야 할 긴급성이 약화됩니다.
  • 프로모션을 자주 하는 벤더의 보드 가격은 양방향으로 오래될 수 있습니다. GLM-5.3-Flash: 11-11 스냅샷은 만료된 출시 프로모션 가격($0.05/$0.18, 2026-09-09 종료, 실제 $0.15/$0.50)을 나열했고 도구가 보정했습니다. 11-20 스냅샷은 $0.02/$0.07(프로모션 종료 후보다 낮음, 새 프로모션 추정)으로 갱신되어 규칙은 2026-11-22에 제거. Cost/Task을 믿기 전에 벤더 가격 페이지에서 확인하세요.
  • 캐시 할인 없음. DeepSeek 캐시 히트 입력 $0.006(피크) / $0.003(비피크); Anthropic 캐시 입력 $0.10–$1.00. 멀티턴 agent 워크로드는 캐시에 자주 히트; 실제 청구서는 「정가 × 토큰」을 크게 밑돌 수 있습니다.

자신의 비용 기준을 쓰고 싶은가? 아래 붙여넣기 상자에서 Cost/Task 열을 당신의 실측 청구서나 셀프호스팅 상각 비용으로 교체하세요 —— 파서는 열 이름을 읽으며 숫자의 출처는 상관하지 않습니다. 얻는 경계선은 당신의 경계선입니다.

  • Rank vs Overall Rank: 전자는 이 하위 보드/라이선스 필터 내 순위; 후자는 전체 모델 종합 순위.
  • Preliminary(임시): 득표가 안정성 임계값에 미달; CI는 보통 넓음.
  • AutoEval(자동 평가): 점수가 인간 대전이 아닌 자동 평가에서 나옴 —— 인간 투표 점수와 직접 비교 불가 → 기본 제외.
