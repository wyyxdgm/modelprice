来源：arena.ai/leaderboard/code/webdev 及其子榜（frontend / fullstack），抓取于 %SCRAPED%；榜单数据日期 %CAPTURED%。

可用性：页面公开可读、可抓取；但 arena.ai/api/* 与 api.arena.ai/* 返回 403（Cloudflare + 路由白名单）—— 没有公开 JSON API。所以本工具采用「内嵌快照 + 粘贴扩展」设计，不做实时请求。

字段语义：

  • Score（分数）：Arena 的 Bradley-Terry 型评分；+u/−d 是 bootstrap 95% 置信区间。
  • Cost/Task (P50)：完成一个 Arena 任务的中位美元成本 = 实测 token 用量 × 下方 API 价格。N/A = 未公布 —— 此类模型默认排除（可开关）。
  • Price $/M：厂商一方 API 标价（输入 / 输出每百万 token）—— 不是 Arena 统一定价，也不是自托管的摊销成本。注意：Cost/Task 低不代表单价低（还取决于模型产出了多少 token）。

这些价格到底是谁的价格？（逐条核对过）

与独立价格索引 benchr.org/pricing（2026-09-11 快照）逐条比对，Arena 的 Price $/M 等于各厂商的官方 API 标价： Kimi K3.1 Pro $2/$10、Kimi K3 $3/$15（Moonshot）；GLM-5.2 / 5.3 $1.40/$4.40（Z.ai）；Claude Opus 5.5 $4/$20、Sonnet 5.5 $2/$10、Haiku 5.5 $0.10/$0.50（Anthropic）；GPT-6.1 Sol $2/$10、Terra $1/$5、GPT-6 Astra $10/$50（OpenAI）；Grok 4.7 $2/$6、Gemini 4 Argon $2/$10；Mistral Large 4 $0.70/$2.10；MiniMax M3 $0.30/$1.20；DeepSeek V4-Pro $1.32/$3.96。

开源模型挂的也是 API 价 —— 不是你自托管要付的钱。Gemma 4 31B $0.16/$0.47、Granite 4.1 8B $0.05/$0.10、Hy3 $0.13/$0.53、Qwen3.8-27B $0.40/$3、MiMo-V2.6-Flash $0.14/$0.28 —— 这些是 Google / IBM / 腾讯 / 阿里 / 小米自家托管端点的报价（榜上各模型链接指向那些 API 文档）。开放权重 ≠ 免费推理：自托管成本是 GPU 摊销 + 电费 + 运维，与每 token 标价没有换算关系。

Cost/Task 是按实测用量算的 —— 三个内部证据：

  • 同一个模型的 Price $/M 在本工具全部 7 张榜上完全一致 → 单价是模型级常量；
  • 同一个模型的 Cost/Task 在五个 WebDev 子榜（Overall / Frontend / React / Reference-based / Fullstack）上完全一致，但在 Image-to-WebDev 上不同（例：DeepSeek-V4.1-Flash-20261017：$0.12 vs $0.10）→ 用量按任务类别聚合，不按子榜；
  • Agent 榜还公布 Output Tokens/Task，据此可反推输入量：14 个模型反推为 125K–1.27M 输入 token，输入/输出比 3.8–17.9× —— 正是多轮工具调用的负载特征。而 (Max)/(High)/(xHigh) 档共用同一单价但 Cost 差 2–4×（Claude Opus 5.5：$5.66 vs $2.13）—— 纯粹是用量差异。

三个让结论偏乐观的价格陷阱：

  • DeepSeek 峰谷价。榜面把 20261017 版标为谷价 $0.15/$0.60、20260910 版标为峰价 $0.30/$1.20。峰时 = 工作日 01:00–04:00 与 06:00–10:00 UTC；其余时段半价。如果你的负载排不进谷时，20261017 的 $0.12/任务会翻倍到 ~$0.24：它仍守住 1664 档（结构不变），但「1638→1664」的边际价从 $0.0027/分 涨到 $0.0073/分，「1664→1687」从 $0.0343 降到 $0.0291 —— 膝点跳跃从 12.8× 缩到 4.0×，削弱了「停在 1664」的紧迫性。
  • GLM-5.3-Flash 用的是已过期的首发促销价 $0.05/$0.18；促销 2026-09-09 结束，现价 $0.15/$0.50（3×），所以它的 $0.15/任务实际约 $0.45。它本来就不在前沿上，但类似的过期促销价可能虚高了其他模型。
  • 无缓存折扣。DeepSeek 缓存命中输入 $0.006（峰）/ $0.003（谷）；Anthropic 缓存输入 $0.10–$1.00。多轮 agent 负载经常命中缓存；真实账单可能远低于「标价 × token」。
