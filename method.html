Method & data sources

How the frontier is computed, where every number comes from, and what this tool deliberately does not claim.

The question

Comparison sites show prices; leaderboards show scores. This tool joins them and answers a decision-grade question: given the minimum Arena Score you can accept (threshold T), which model has the lowest measured cost per task? Formally C(T) = min{cost : score ≥ T}. Sweeping T downward yields the cost-quality Pareto frontier — a staircase where each flat segment is the score range one model rules. The table also reports the marginal price of moving up one tier (Δcost/Δscore in $/point), which is the number purchasing decisions actually turn on.

Three definitions of “best value”

  • Threshold (default): cheapest model with score ≥ T. The only definition that is correct constrained optimization.
  • Score per $: strongly biased toward cheap models because Arena’s Bradley-Terry scores carry a ~1200 baseline offset.
  • Excess score per $: subtracts the 1200 floor first; closer to marginal value, still biased.

Data sources & snapshot dates

  • Scores and Cost/Task: the public arena.ai WebDev leaderboards and sub-boards, snapshot 2026-11-11 (scraped 2026-11-14). For automated refresh prefer the official machine-readable mirror: lmarena-ai/leaderboard-dataset on Hugging Face.
  • Prices: each vendor’s first-party API list price (input/output per $1M tokens), verified item-by-item against benchr.org/pricing (2026-09-11 snapshot). Open models are listed at their vendor-hosted API price, not self-hosting cost.
  • Cost/Task (P50) = median measured token usage of an Arena task × list price — a cache-miss basis. P50 hides the tail (P95 can be 5–10×) and covers token spend only.

Price as a function of time

List prices change by hour and by calendar. Verified rules applied by default: DeepSeek peak/off-peak (peak = weekdays 01:00–04:00 & 06:00–10:00 UTC, 2×; otherwise ½×) — the board itself mixes peak-priced and off-peak-priced rows of the same family; GLM-5.3-Flash promo expiry (2026-09-09: $0.05/$0.18 → $0.15/$0.50); Gemini 4 Carbon/Argon hike on 2026-12-01 ($2/$10 → $4/$20). Uncertain rules (DeepSeek V4-Flash peak split; two models 2× off vs a third-party index) are included but off by default.

Cache model

Leaderboard costs assume 0% cache hits, which systematically overestimates agent workloads. Effective input price = (1−h)·pin·wm + h·pin·ratio; output is never discounted. Cache read prices are stored as a ratio of list input price (DeepSeek 2–3.3%, MiMo 0.8–2%, Kimi 10–20%, GLM 18–20%, Hy3/Grok 25%, Anthropic 2.5–10%, OpenAI 5–10%, Gemini 5%, Mistral 10.3%; unknown → 10% estimate, labeled). Write multiplier wm = 1.25× for Anthropic/OpenAI (model names starting Claude/GPT-), else 1.0×. At h=95% top models drop 59–79% in effective cost and the frontier itself re-orders.

Strict CI mode

Adjacent tiers whose 95% CIs overlap are merged (cheaper model kept) so you don’t pay for statistical noise. Note this is a conservative overlap screen, not a formal test of score differences.

Limitations

  • Scores are a snapshot; capability drifts as boards update. Prices drift weekly.
  • P50 task cost is a workload mix; your workload differs. Use the paste-to-extend feature with your own bills.
  • The all-license board covers only its top 41 rows; the open-source boards are complete.
  • Confidence: every number here traces to a public page; corrections carry per-rule sources in the tool.
