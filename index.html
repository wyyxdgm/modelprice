Cheapest AI models at every quality level — Arena Score vs. real cost per task

Model comparison sites show prices. Leaderboards show scores. This tool joins them: set the minimum Arena Score you can accept, and it names the cheapest model that clears the bar — plus the marginal $/point to the next tier. Arena's official leaderboard prices hide three traps that this tool corrects: DeepSeek peak/off-peak pricing (the board mixes both conventions in one table), expired promo prices (GLM-5.3-Flash), and cache-miss bias (leaderboard costs assume 0% cache hits; real agent workloads hit often).
